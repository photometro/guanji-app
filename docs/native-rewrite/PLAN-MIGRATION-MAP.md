# 原生化计划编号迁移图

## 编号策略

旧任务编号是历史证据，不能重新解释或覆盖。即使某些编号只存在于未提交工作区和 Dify 实施报告中，也必须保留，避免以后检索时把两次实现混为一谈。

因此：

- 复用的是版本槽位 `v4.2.0`–`v4.2.8`；
- 不复用已出现过的任务编号；
- 新路线从 #271 开始；
- #255–#270 作为本地实验/补救/测绘编号保留区，不再分配新含义。
- #275–#280 只迁移经典/普通模式；玻璃模式继续由 WebView 唯一渲染。
- #281 删除全部旧 JS 核心后，玻璃请求先安全回落到 Native 经典界面；玻璃 Native 另立任务，直接从 NativeRoute 重构。

- 洞悉系统原生改版在 #281 完成后重新编号为 v4.3.x 独立计划；不复用 #265–#269。
