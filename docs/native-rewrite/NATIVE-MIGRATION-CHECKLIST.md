# WebView → Compose 原生化长期检查清单

用途：所有后续页面原生化的实施前、实施中、实施后和发布前检查。<br>
基线优先：当前以 v4.1.5 WebView 为事实源；后续若基线变更，必须重新冻结并记录 commit。

## A. 实施前：范围、入口和事实源

- [ ] 明确任务编号、版本节点、基线 commit、APK、包名和构建签名。
- [ ] 明确唯一入口、前台 Activity、route、来源页、返回目标和关闭优先级。
- [ ] 明确页面/区域 owner：WebView、NativeRoute 或同根 Sheet；同一状态不得双重渲染。
- [ ] 读取目标 HTML、CSS、JS、SVG、动画、手势、键盘和数据桥，不以旧原生页面或上一张截图代替。
- [ ] 冻结浅色、深色、降低透明度、玻璃、空数据、单条、密集、长文案、大字号和键盘状态。
- [ ] 固定 viewport、分辨率、density、fontScale、导航模式、系统栏和设备品牌。
- [ ] 建立元素映射表：selector → Compose 节点 → owner → 状态 → 证据来源。
- [ ] 建立允许修改的文件白名单；禁止顺手修改未迁移页面的业务逻辑。

## B. 静态 UI 与几何

- [ ] 页面背景、容器宽度、左右边距、顶部起点、底部安全区与 WebView 一致。
- [ ] 卡片/Sheet/对话框的宽度、高度、最大高度、圆角、阴影、描边和层级已登记。
- [ ] 标题、副标题、标签、正文、元信息的字体、字重、字号、行高、字间距和 baseline 已登记。
- [ ] 已记录 Compose `includeFontPadding`、字体回退和中文字体实际渲染差异。
- [ ] 每个图标复用原 SVG path/viewBox/stroke/currentColor/画布尺寸；禁止用系统图标替代。
- [ ] 所有 padding、margin、gap、min/max size 都能追溯到 CSS 或运行时 bounds。
- [ ] 1 位、2 位、3 位数字和长文案均无裁切、挤压或异常换行。
- [ ] 分割线只在 WebView 有的层级出现；阴影、受光层和内容层不互相遮挡。
- [ ] 浅色、深色、降低透明度和系统字体放大至少各检查一次。

## C. 组件和 Material 默认行为

- [ ] 判断控件语义：普通按钮、分段选择、滑块、Chip、Sheet、Dialog，不误套用 Material 组件。
- [ ] 明确覆盖默认最小触控尺寸、内边距、形状、颜色、文字样式和状态层。
- [ ] 无未登记 system ripple、pressed overlay、scale、弹簧回弹或默认阴影。
- [ ] 主/次/危险按钮复用项目既有颜色和无障碍语义。
- [ ] 文本输入、滑块、Chip、Tab、Footer 使用统一项目组件或明确登记的页面变体。

## D. 位置、安全区和滚动

- [ ] NativeRoot 单点读取 status/navigation/IME insets，记录单位（px/dp）和转换方式。
- [ ] Sheet、全屏计时、固定 footer、Bottom Tab 均只消费一次 safe-area。
- [ ] 没有页面级猜测手势条高度或用固定屏幕高度模拟键盘。
- [ ] 长内容只有内容区滚动；footer 固定且不被滚动内容挤走。
- [ ] 记录滚动区域的 max height、scroll range、滚动条样式和触摸行为。
- [ ] 键盘出现/关闭、横竖屏、窄屏、魅族底部横条和三键导航均不重叠。

## E. 动画和手势

- [ ] 记录进入/退出动画的触发条件、属性、时长、缓动、关键帧和清理时机。
- [ ] Sheet 与遮罩的动画时序符合 WebView；不能因父级变更失去底部对齐。
- [ ] 首帧不等待非必要桥接；异步数据补齐不改变首帧层级。
- [ ] 抓手拖动、点击遮罩、系统 Back、按钮点击分别测试。
- [ ] 记录拖动热区、关闭阈值、短距离回位、取消和 reduced-motion 分支。
- [ ] 反复打开/关闭、快速点击和 Activity 重建不会触发旧回调清理新状态。

## F. 状态、数据、返回和恢复

- [ ] 先画状态机，再写 Compose：空闲、时间、详情、运行、汇总、关闭等状态互斥明确。
- [ ] 来源页和子 Sheet 使用 ownership/stack；关闭子层后回到来源层，而不是恢复全局 Tab。
- [ ] WebView/Room/Native 只有一个业务写入权威；原生只调用既有 UseCase/桥。
- [ ] 新建、编辑、补记、删除、保存、取消、重复点击均幂等。
- [ ] Android Back 优先级明确：IME → 当前步骤 → 子 Sheet → 来源 Sheet → 首页。
- [ ] 计时、输入、选择状态在 Activity 重建、后台恢复、强制停止后符合 WebView 语义。
- [ ] 旧记录、旧备份、未知字段、时区和空数据不因页面迁移丢失。

## G. 性能与响应

- [ ] 首次打开首帧在可接受时间内显示，不等待全量记录或 AI 请求。
- [ ] 桥接输入为最小渲染上下文；不把全量原始记录来回序列化。
- [ ] 列表使用稳定 key；统计和派生值不在每个卡片重组时重复全量计算。
- [ ] 键盘、滚动、动画和高密度选项下无明显掉帧、卡死或 ANR。
- [ ] 设备日志无 FATAL、ANR、Window 泄漏、非法状态或重复写入。

## H. 运行时证据与闸门

- [ ] 浏览器和 Native 使用同 viewport、fixture、主题、fontScale、键盘和采样时刻。
- [ ] 证据记录 `topResumedActivity`、route、owner、dataRevision、Tab 数量和 Sheet 层级。
- [ ] 同状态截图、DOM/Compose bounds、UI dump、动画首/中/终帧全部存在。
- [ ] 共享组件误差 ≤1dp，页面容器误差 ≤2dp，动画关键帧误差 ≤3dp；文案/图标/层级/返回关系零差异。
- [ ] 明确检查：白屏、白条、黑色覆盖、ripple、scale、bounce、clipping、footer 漂移、Tab 重叠。
- [ ] 静态脚本通过后仍完成真机运行时对照；不能只凭类存在或 APK 可启动签收。
- [ ] 构建摘要、APK 哈希、签名、安装包版本和测试日志齐全。
- [ ] 失败时标记“待视觉修复”，不升级下一节点、不发布、不上传成功报告。

## I. #276 Regression Checklist

每次修改记录、计时、补记、详情、首页日历入口或共享 Sheet/Tab 时，必须逐项复测：

### 入口与层级

- [ ] 首页点击记录：首页仍保留在遮罩下方，无白屏、空壳或第二 Activity。
- [ ] 记录 Sheet 打开后立即检查和延迟 3 秒检查：底部 Tab 节点保留但重叠区域由遮罩/Sheet 覆盖，不可点击且不出现在无障碍子树。
- [ ] 日历 Sheet 打开后立即检查和延迟 3 秒检查：底部 Tab 节点保留但重叠区域由遮罩/Sheet 覆盖，不可点击且不出现在无障碍子树。
- [ ] 记录/日历关闭必须采集连续帧：Tab 随 Sheet 下移与遮罩淡出连续揭示；不得出现 Sheet 已消失、Tab 仍缺席，随后 Tab 单独显现的阶段。
- [ ] NativeRoute 页面、Tab、遮罩/Sheet 的绘制顺序固定为 `页面 → Tab → 遮罩/Sheet`；弹层生命周期不得修改整个页面宿主 elevation，不得在内联 Tab 与独立迁移宿主之间切换。
- [ ] 日历 → 补记 → 返回：仍回到日历，Tab 保持在遮罩下，不提前恢复交互。
- [ ] 关闭记录后回到来源页；关闭日历后才恢复 Tab。
- [ ] 记录/日历抓手拖动、遮罩点击、系统 Back 的关闭优先级正确。

### 时间与记录方式

- [ ] “就现在”初始显示 `00:00`，并显示“直接填写”入口。
- [ ] “就现在 / 补记”分段控件高度、圆角、选中层、字体和内边距与 WebView 一致。
- [ ] 补记日期和时间显示本地值，选择器打开/取消/确认路径正确。
- [ ] 直接填写返回后仍处于“就现在”并恢复 `00:00` 语义。
- [ ] 编辑、补记、新建不会改变 WebView 的 `quick/timer` 偏好或主流程语义。

### 计时运行与汇总

- [ ] 计时运行使用 WebView 深蓝背景、数字尺寸/位置和底部按钮比例。
- [ ] 开始、结束、取消、后台、重启、Activity 重建后计时状态一致。
- [ ] 计时通知按钮与 App 内状态同步，重复结束/取消幂等。
- [ ] 结束汇总仍是深蓝全屏，包含小勾图标、正确文字颜色、字号和行距。
- [ ] 保存后只产生一条记录，返回首页并刷新统计/最近记录。

### 时长、状况与备注

- [ ] 顶部时长滑条默认显示“未记录”。
- [ ] 拖动滑条后实时显示分钟数；最小、最大和回到未记录均正确。
- [ ] 发生前状况胶囊的背景、边框、圆角、颜色、选中态与 WebView 一致。
- [ ] 15 项默认选项、添加选项、自定义项删除和确认流程可用。
- [ ] 删除自定义项的确认按钮使用既有蓝色主操作样式，不被 Sheet 遮挡。
- [ ] 多选组合、`none/unsure` 互斥规则和旧记录兼容不变。
- [ ] 备注框高度、placeholder、可输入性、滚动定位和键盘行为与 WebView 一致。
- [ ] 备注到固定 footer 的间距紧凑且稳定，footer 不被键盘或手势条遮挡。

### 字体、布局和安全区

- [ ] 标题、标签、时间、按钮、备注和辅助文字的字号/字重/行高/baseline 与基线一致。
- [ ] 大字号、长文案、窄屏下无文字裁切或“被圆形框住”的现象。
- [ ] Sheet 顶部抓手、内容区、footer 的真实 bounds 与 WebView 对照。
- [ ] status/navigation/IME insets 仅消费一次；魅族底部横条不压住按钮。
- [ ] 页面滚动时 footer 固定；内容过多时只滚动内容区。

### 性能与历史回归

- [ ] 点击记录后首帧立即出现，不依赖 500ms 级完整上下文等待。
- [ ] 添加状况自动聚焦并拉起键盘；备注点击后输入法可正常显示和关闭。
- [ ] 快速打开/关闭、重复点击、前后台切换无旧动画回调串入。
- [ ] 不出现白屏、白条、黑色覆盖、系统 ripple、额外缩放、未登记回弹、ANR 或崩溃。
- [ ] 每项已修问题都在本次证据 manifest 中有结果；不能只引用历史截图。

### #277 洞悉 AI 增强观察补充回归

- [ ] AI 卡片的 `Header / AnalysisContent / Intro / ActionArea / Disclaimer` 分区和 WebView selector 对照已登记。
- [ ] 初始、生成中、成功/缓存、失败四种状态均可触发或有明确 fixture；“无法触发”不得写成动态验证通过。
- [ ] 点击重新生成后，已有分析和介绍保留；只替换动作区；免责声明按 WebView 规则隐藏。
- [ ] 动作区保持固定高度，显示左对齐 spinner 与“正在生成 AI 增强观察…”；按钮恢复后无 Layout Shift。
- [ ] 加载完成后新分析、重新生成按钮和免责声明恢复；失败时最后可信内容不被清空或覆盖。
- [ ] 先轮询 UI 树/DOM 语义条件，再截取截图；XML/DOM、截图、时间戳和触发动作使用同一 evidence id。
- [ ] 动作区 padding、标题/介绍/声明 gap 与 WebView CSS/computed style 及 Compose token 一一对应。
- [ ] `verify:277`、`verify:native-ui-v2:preflight -- 277` 和受影响历史 verifier 的版本/缓存断言同步通过。
- [ ] Dify 报告同时记录接收、索引和可检索状态；HTTP 200 或 document id 不能单独作为成功条件。

## J. 复盘闭环

- [ ] 新问题记录“现象、入口、状态、设备、根因、修复、证据”。
- [ ] 能跨页面复用的规则同步到 `docs/REUSE-RULES.md`，包括职责、入口、边界和验证方式。
- [ ] 视觉契约、状态矩阵、迁移台账和 Regression Checklist 同步更新。
- [ ] 仅一次性微调不进入公共 token；公共 token 必须有 WebView 来源。
- [ ] 下一任务开始前读取本清单和上一任务的失败复盘，确认没有把已修问题重新引入。

## K. #278 设置/AI 设置回归清单

每次修改“我的”、设置、AI 设置、数据与隐私或相关弹层时，必须逐项复测：

- [ ] `me` 路由只由现有 `MainActivity → NativeRoot` 承担；没有第二个设置 Activity、透明占位页或重复 Tab。
- [ ] 经典浅色、经典深色、降低透明度和大字号下，页面标题、卡片圆角/阴影、分段控件、开关、滑块、行间距与 WebView 契约一致；玻璃模式继续由 WebView 唯一渲染。
- [ ] 页面可滚动到外观、记录设置、提醒/通知、反馈设置、AI 设置、数据与隐私、危险操作和关于入口；底部 Tab 不遮挡内容。
- [ ] 设置快照异步到达期间不覆盖用户已保存值；旋转、返回、进程重建和重启后设置状态仍来自既有 JS/SecureStorage。
- [ ] AI 已配置态显示 Provider/模型与编辑入口；新建/编辑态显示 Base URL、模型和掩码密钥；保存空密钥不会清空旧密钥。
- [ ] API Key、Base URL 和模型不会出现在日志、快照、Compose UI dump、截图索引或错误文案中。
- [ ] 主题、记录方式、提醒时间、实况通知、每日话语、保护模式、数据范围的开关/选择状态和点击反馈与 WebView 一致。
- [ ] 需要系统选择器或 WebView Sheet 的操作只显示一个弹层；返回键先关闭子层，再恢复来源页 Native 所有权。
- [ ] AI 连接测试、实况通知测试的 loading/成功/失败状态不清空卡片、不自动聚焦输入框，完成后只刷新派生快照。
- [ ] 构建必须通过 `tools/build-apk.ps1 -Mode debug -Install`、版本/缓存标识检查和 `verify:278`；真机至少覆盖魅族 Flyme 一次。
- [ ] 设置页每个卡片的 spacing 只能来自 `SettingsMetrics`；真机 UI dump 不得出现重复的“实验性”状态或 WebView 不存在的模型选择器。
- [ ] 记录/日历弹层打开时，唯一活动 Native Tab 必须保持在同一 Compose 树和原 bounds，仅关闭点击、焦点与无障碍；不得由 `setNativeTabEnabled(false)`、宿主 elevation 切换或异步旧回调制造显隐，Sheet/遮罩负责覆盖重叠区域。
- [ ] 实况通知状态区保持扁平层级（无额外包框），状态文案/结果文案与 WebView 快照一致；分段未选中背景必须为 `--bg-elev` 对应深灰 token。
- [ ] 关于卡片使用已登记的栅格图标资源，隐私说明保留 WebView 的两条 bullet；Compose 不直接加载自适应 XML 图标。
- [ ] 每次设置点击都验证“先有视觉反馈、后异步持久化”：不得因桥接、存储或网络等待造成明显点击延迟。
