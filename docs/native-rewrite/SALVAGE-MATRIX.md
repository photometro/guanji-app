# UI 原生化 V1 资产取舍矩阵

## 判定等级

| 等级 | 含义 |
| --- | --- |
| A 直接保留 | 已在 v4.1.5 稳定基线中，继续作为权威实现 |
| B 审查后移植 | 思路或非 UI 能力有价值，但必须脱离旧宿主并独立验证 |
| C 仅作证据 | 只用于测绘、对照和避免重犯，不进入运行时代码 |
| D 明确弃用 | 架构方向错误，禁止继续复用 |

## 移植规则

任何 B 类资产必须满足：

1. 生成独立 diff，不夹带 UI 页面、Manifest Activity 或版本号修改；
2. 说明输入、输出、数据权威和失败回滚；
3. 通过 v4.1.5 原有回归；
4. 不改变 WebView 现有行为；
5. 真机验证后才能进入 V2 分支。

任何 C 类资产只能被引用，不能通过目录复制整体进入运行时。
