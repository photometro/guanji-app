## v3.10 更新介绍（预发行版）

> ⚠️ **预发行版**：WebDAV 备份为新功能，后续还会继续优化打磨，正式版再标记稳定。

本版本带来**数据离机备份通道**与默认样式调整。

### ✨ 新增：WebDAV 备份（加密模式专属）
- 配置你自己的 WebDAV 服务器（坚果云 / 群晖 / Nextcloud）——备份上传的是**密文**，只有你的口令能解开，——观己不提供任何云服务
- 配置 + 连接测试（密码存系统安全存储，建议使用服务的「应用专用密码」）
- **手动备份**：自动建 `guanji/` 目录，文件名带设备标识，多份历史全保留
- **切后台自动备份**（默认关，数据有变化才上传——指纹去重）
- **从服务器恢复**：合并 / 新增 / 覆盖三模式（覆盖前自动把当前数据备份到本机）
- **服务器备份管理**：列表 / 删除；清除全部数据时可连带删除服务器备份
- 明文模式显示「开启加密后可用」——服务器备份是加密通道

### 🎨 优化
- **新用户默认经典样式**：玻璃效果默认关闭（实验性功能保守默认），老用户设置保留、可随时开启
- **隐私文案统一**：「数据默认仅存本地；WebDAV 备份由你自选——上传的是密文」
- 修改口令提示：历史备份（含服务器）仍需创建时的口令

### 🛠 技术
- 自建原生 WebDAV 桥（okhttp，支持任意 WebDAV 方法），绕开 WebView CORS 限制

### 🔒 隐私承诺
- 记录默认只保存在这台设备上；WebDAV 备份由你自选，上传的是密文；AI 分析仅上传聚合统计特征，不涉及单条记录
